# 1-2 minute walkthrough script (screen recording)
1. (0:00) Open the live URL. Say: "ExamRunway turns an exam date and topics into a daily checklist."
2. (0:10) Click Plan my exam. Submit with a blank form to show errors. Fix them: exam name, a date 10 days ahead, 3 hours, tick Sunday as a rest day.
3. (0:30) On Topics, click Add with an empty name (error). Add 3 topics with different difficulty and confidence. Delete one and re-add it.
4. (0:55) Click Create my plan. Point out the toast, the heavier days for hard topics, the Revision badges, and the Today badge.
5. (1:15) Tick a few tasks: show the progress bar and Done badge. Click Copy plan.
6. (1:30) Resize the window to phone width. Reload the page to show the saved plan, then close.
